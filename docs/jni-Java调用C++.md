# JNI 使用完整步骤流程文档

## 文档说明

本文档详细描述了在 Android Studio 环境下，基于 NDK + CMake 实现 JNI（Java Native Interface）的完整流程，涵盖「Java 声明 Native 方法→C/C++ 实现→编译→调用」全链路，适用于需要在 Android 应用中实现 Java/Kotlin 与 C/C++ 代码交互的开发场景。

## 前置条件

1. Android Studio 已安装「NDK」和「CMake」：

    - 打开 AS → `File > Settings > Appearance & Behavior > System Settings > Android SDK > SDK Tools`；

    - 勾选「NDK (Side by side)」「CMake」，点击 Apply 安装（建议选 25.x 以上版本）。

2. 项目已配置 NDK 支持（AGP 7.0+ 自动适配，无需额外配置）。

## 完整步骤流程

### 步骤 1：在 Java/Kotlin 中声明 Native 方法

在 Java/Kotlin 类中定义需要调用 C/C++ 的 Native 方法，使用 `native` 关键字修饰，无需实现体，并加载后续编译生成的原生库。

**示例文件**：`app/src/main/java/com/example/jnidemo/JNIUtils.java`

```Java
package com.example.jnidemo;

public class JNIUtils {
    // 1. 加载编译后的原生库（库名对应CMake配置的名称，无lib前缀、无.so后缀）
    static {
        System.loadLibrary("native-lib"); // 核心：加载so库，名称要和CMakeLists.txt中一致
    }

    // 2. 声明Native方法（无实现体，由C/C++实现）
    // 示例1：简单字符串返回
    public native String getNativeString();
    // 示例2：传递参数（int）并返回计算结果
    public native int add(int a, int b);
    // 示例3：传递Java对象（自定义Person类）
    public native String getPersonInfo(Person person);
}

// 自定义Java实体类（用于示例3）
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 必须提供getter，C/C++通过JNI调用
    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }
}
```

### 步骤 2：生成 JNI 头文件（可选但推荐）

JNI 方法的函数名有严格规范（包名+类名+方法名），手动编写易出错，可通过 `javac` 命令自动生成头文件，作为 C/C++ 实现的参考。

#### 操作步骤

1. 打开 Android Studio 的「Terminal」终端，进入 Java 类的包目录上级：

    ```Bash
    cd app/src/main/java
    ```

2. 执行 `javac` 命令生成头文件（指定 `-h` 参数，输出目录为 `jni`）：

    ```Bash
    # 语法：javac -h 输出目录 完整类路径.java
    javac -h ../jni com/example/jnidemo/JNIUtils.java
    ```

3. 生成结果：在 `app/src/main/jni` 目录下生成 `com_example_jnidemo_JNIUtils.h` 头文件，核心内容为方法签名，示例片段：

    ```C
    /* DO NOT EDIT THIS FILE - it is machine generated */
    #include <jni.h>
    /* Header for class com_example_jnidemo_JNIUtils */
    
    #ifndef _Included_com_example_jnidemo_JNIUtils
    #define _Included_com_example_jnidemo_JNIUtils
    #ifdef __cplusplus
    extern "C" {
    #endif
    /*
     * Class:     com_example_jnidemo_JNIUtils
     * Method:    getNativeString
     * Signature: ()Ljava/lang/String;
     */
    JNIEXPORT jstring JNICALL Java_com_example_jnidemo_JNIUtils_getNativeString
      (JNIEnv *, jobject);
    
    /*
     * Class:     com_example_jnidemo_JNIUtils
     * Method:    add
     * Signature: (II)I
     */
    JNIEXPORT jint JNICALL Java_com_example_jnidemo_JNIUtils_add
      (JNIEnv *, jobject, jint, jint);
    
    /*
     * Class:     com_example_jnidemo_JNIUtils
     * Method:    getPersonInfo
     * Signature: (Lcom/example/jnidemo/Person;)Ljava/lang/String;
     */
    JNIEXPORT jstring JNICALL Java_com_example_jnidemo_JNIUtils_getPersonInfo
      (JNIEnv *, jobject, jobject);
    
    #ifdef __cplusplus
    }
    #endif
    #endif
    ```

### 步骤 3：创建 C/C++ 实现文件

在 `app/src/main/jni` 目录下创建 C/C++ 文件（如 `native-lib.cpp`），实现头文件中声明的 JNI 方法。

**示例文件**：`app/src/main/jni/native-lib.cpp`

```C++
// 引入JNI头文件（NDK自带）
#include <jni.h>
// 引入自动生成的头文件（可选，直接复制方法签名也可）
#include "com_example_jnidemo_JNIUtils.h"
// 引入字符串处理头文件
#include <string>

// 示例1：实现getNativeString方法
JNIEXPORT jstring JNICALL Java_com_example_jnidemo_JNIUtils_getNativeString
        (JNIEnv *env, jobject thiz) {
    // jstring是Java字符串的JNI类型，需用env->NewStringUTF转换C++字符串
    std::string hello = "Hello from C++ (JNI)";
    return env->NewStringUTF(hello.c_str());
}

// 示例2：实现add方法（接收两个int参数，返回和）
JNIEXPORT jint JNICALL Java_com_example_jnidemo_JNIUtils_add
        (JNIEnv *env, jobject thiz, jint a, jint b) {
    return a + b; // jint对应Java的int，直接计算返回
}

// 示例3：实现getPersonInfo方法（操作Java对象）
JNIEXPORT jstring JNICALL Java_com_example_jnidemo_JNIUtils_getPersonInfo
        (JNIEnv *env, jobject thiz, jobject person_obj) {
    // 1. 获取Person类的Class对象（参数：Java对象）
    jclass person_cls = env->GetObjectClass(person_obj);
    if (person_cls == nullptr) { // 空指针检查，避免崩溃
        return env->NewStringUTF("Person class not found");
    }

    // 2. 获取getName方法的ID（参数：类、方法名、方法签名）
    // 方法签名规则：(参数类型)返回类型，Ljava/lang/String; 对应String
    jmethodID getName_mid = env->GetMethodID(person_cls, "getName", "()Ljava/lang/String;");
    // 3. 获取getAge方法的ID
    jmethodID getAge_mid = env->GetMethodID(person_cls, "getAge", "()I");

    // 4. 调用Java对象的getter方法，获取属性值
    jstring name_jstr = (jstring) env->CallObjectMethod(person_obj, getName_mid);
    jint age = env->CallIntMethod(person_obj, getAge_mid);

    // 5. 转换jstring为C++字符串
    const char *name_cstr = env->GetStringUTFChars(name_jstr, nullptr);
    std::string info = "Person: " + std::string(name_cstr) + ", Age: " + std::to_string(age);

    // 6. 释放资源（避免内存泄漏）
    env->ReleaseStringUTFChars(name_jstr, name_cstr);
    env->DeleteLocalRef(person_cls); // 释放局部引用

    // 7. 返回拼接后的字符串
    return env->NewStringUTF(info.c_str());
}
```

### 步骤 4：编写 CMakeLists.txt 构建配置

CMake 是 NDK 的构建工具，通过 `CMakeLists.txt` 定义编译规则（指定源码、输出库名、依赖等）。

**示例文件**：`app/src/main/jni/CMakeLists.txt`

```CMake
# 1. 指定CMake最低版本（需和AS安装的CMake版本匹配）
cmake_minimum_required(VERSION 3.22.1)

# 2. 定义项目名称（自定义）
project("jnidemo")

# 3. 创建共享库（.so库）
# add_library(库名 类型 源码文件)
# SHARED：动态库（.so），STATIC：静态库（.a）
add_library(
        native-lib # 输出库名，对应Java中System.loadLibrary("native-lib")
        SHARED     # 动态库
        native-lib.cpp # 要编译的C/C++文件（多个文件用空格分隔）
)

# 4. 链接NDK内置库（可选，比如log库用于C/C++打印日志）
find_library(
        log-lib # 给库起别名
        log     # NDK内置的log库（android/log.h）
)

# 5. 链接依赖库（将log库链接到native-lib）
target_link_libraries(
        native-lib
        ${log-lib}
)
```

### 步骤 5：在 build.gradle 中配置 CMake

告知 Gradle 使用 CMake 编译原生代码，并指定 `CMakeLists.txt` 路径。

**配置位置**：`app/build.gradle`（android 闭包内）

```Plain Text
android {
    compileSdk 34

    defaultConfig {
        applicationId "com.example.jnidemo"
        minSdk 21
        targetSdk 34
        versionCode 1
        versionName "1.0"

        testInstrumentationRunner "androidx.test.runner.AndroidJUnitRunner"

        // 配置NDK编译的CPU架构（按需选择，减少APK体积）
        ndk {
            abiFilters 'arm64-v8a', 'armeabi-v7a' // 主流架构，x86/x86_64可省略
        }
    }

    // 核心：配置CMake构建
    externalNativeBuild {
        cmake {
            path "src/main/jni/CMakeLists.txt" // CMakeLists.txt的路径
            version "3.22.1" // CMake版本（和步骤4的最低版本一致）
        }
    }

    buildTypes {
        release {
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
    compileOptions {
        sourceCompatibility JavaVersion.VERSION_1_8
        targetCompatibility JavaVersion.VERSION_1_8
    }
}
```

### 步骤 6：同步项目并编译生成 .so 库

1. 点击 Android Studio 右上角的「Sync Now」同步 Gradle 配置；

2. 编译项目（Build > Make Project）；

3. 编译成功后，.so 库生成路径：`app/build/intermediates/cmake/debug/obj/[架构]/libnative-lib.so`（架构如 arm64-v8a、armeabi-v7a）。

### 步骤 7：在 Java/Kotlin 中调用 Native 方法

在 Activity/Fragment 等组件中实例化声明 Native 方法的类，调用对应的 Native 方法。

**示例文件**：`app/src/main/java/com/example/jnidemo/MainActivity.java`

```Java
package com.example.jnidemo;

import androidx.appcompat.app.AppCompatActivity;
import android.os.Bundle;
import android.widget.TextView;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // 1. 实例化JNI工具类
        JNIUtils jniUtils = new JNIUtils();

        // 2. 调用Native方法：获取字符串
        String nativeStr = jniUtils.getNativeString();
        TextView tv1 = findViewById(R.id.tv_native_str);
        tv1.setText(nativeStr);

        // 3. 调用Native方法：加法计算
        int sum = jniUtils.add(10, 20);
        TextView tv2 = findViewById(R.id.tv_add);
        tv2.setText("10 + 20 = " + sum);

        // 4. 调用Native方法：操作Java对象
        Person person = new Person("张三", 25);
        String personInfo = jniUtils.getPersonInfo(person);
        TextView tv3 = findViewById(R.id.tv_person);
        tv3.setText(personInfo);
    }
}
```

## 关键避坑点

1. **库名匹配**：`System.loadLibrary("native-lib")` 的库名必须与 `CMakeLists.txt` 中 `add_library` 的库名一致（无 lib 前缀、无 .so 后缀）；

2. **方法签名错误**：JNI 方法名需严格遵循「Java_包名_类名_方法名」（包名的 `.` 替换为 `_`），参数/返回值类型需匹配 JNI 类型；

3. **内存泄漏**：C/C++ 中调用 `env->GetStringUTFChars` 后必须调用 `ReleaseStringUTFChars`，局部引用（如 `jclass`）需用 `DeleteLocalRef` 释放；

4. **架构适配**：若设备为 arm64-v8a 架构，仅编译 armeabi-v7a 会导致 `UnsatisfiedLinkError`；

5. **权限问题**：部分 NDK API（如访问硬件）需在 `AndroidManifest.xml` 中声明对应权限。
